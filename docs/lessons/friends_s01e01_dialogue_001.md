### Cultural Annotations

#### "bro"
- 美式口语，朋友 / 兄弟之间用
- **不要**对老人 / 上司用
- 中文最近"老铁 / 兄弟"接近

#### "Come on" 的 3 种语气
1. **催促**：Come on, let's go!（快点走啊！）
2. **不信**：Come on, you can't be serious.（拜托，你不会当真吧）
3. **鼓励**：Come on, you can do it!（加油，你做得到！）
- 本 clip 是第 2 种（不信 / 抱怨）

#### "hump and hair piece"
- 美式幽默 / 夸张吐槽
- 描述对方各种"丑陋特征"
- 类似中文"难道他三头六臂？"

#### Friends 主角介绍（背景）
- Phoebe 在听别人吐槽
- 这场景是六人在中央咖啡厅
- 第一集开场，建立人物关系

## 4. Activities（Gagné 9 事件应用）

### Pre-Watch（30 秒，事件 1-3：吸引注意 / 告知目标 / 唤起 prior knowledge）

**屏幕显示**：
> 🎬 Friends S01E01 — 第一句对白
>
> 📚 你将学到 **6 个 chunks**（短语）+ 美式吐槽语气
>
> 💭 你之前学过 "go out with" 吗？想想它是什么意思？

### First Watch（40 秒，事件 4：呈现内容）

- 视频自动播放
- 双语字幕显示
- 不暂停 / 不打扰

### Vocabulary Mining（2 分钟，事件 5：引导学习）

- 系统自动 highlight 6 个 chunks
- 学习者点击不熟的 → 加入 SRS deck
- 显示 culture annotation pop-ups

**视觉**：
```
"There's got to be something wrong with him."
                ↓ 点击 chunk
┌────────────────────────────────┐
│ there's got to be              │
│ B1 · phrase                    │
│ 一定有；必有                    │
│                                 │
│ 例句：                          │
│ • There's got to be a way out. │
│ • There's got to be a reason.  │
│                                 │
│ [+ 加入复习] [跳过]            │
└────────────────────────────────┘
```

### Detailed Watch（3 分钟，事件 6：诱发表现）

- 视频再播一遍，**每句后自动暂停 2 秒**
- 学习者可点击重听某句
- Speed control: 0.75x / 1x / 1.25x

### Quiz（2 分钟，事件 7-8：评估 + 反馈）

#### 题 1（多选 - Remember）
> "Come on" 在这段对话中表达什么？
> A. 催促快走
> B. 不相信 / 抱怨
> C. 鼓励加油
> D. 邀请来玩
>
> **正确：B**
> 解释：上下文是朋友质疑约会对象，所以是不相信的语气。

#### 题 2（Fill-in - Apply）
> 用 "There's got to be something ___ with..." 完成造句：
> 我尝了这汤，太奇怪了，____________________ this soup.
>
> **答案**：there's got to be something wrong with
> 接受变体：something weird with / odd with

#### 题 3（多选 - Understand）
> "hump and hair piece" 在对白中是什么意思？
> A. 真的怀疑对方有这些特征
> B. 夸张吐槽 / 幽默
> C. 一种约会礼仪
> D. 美国流行新词
>
> **正确：B**

### Production Practice（3-5 分钟，事件 9：增强保留）

#### Shadowing
- 听一遍 → 立刻跟读
- 录音 → AI 比对发音
- 评分（流畅度 / 准确度）

#### 自由造句
> 用 "Come on, you're going out with..." 造一句关于自己朋友的话。
>
> 系统例：
> "Come on, you're going out with my best friend, you'd better be nice to him!"

## 7. Pedagogy Justification

### 为什么这设计？引用 SLA 理论

1. **Krashen i+1**：A2 学习者，clip 含 ~25% B1+ chunks → 稍微 above
2. **Comprehensible Input**：双字幕 + 视觉提供足够 context
3. **Schmidt Noticing**：自动 highlight 6 chunks → 主动 noticing
4. **Lexical Approach (Lewis)**：教 chunks（"come on" / "there's got to be"）而非孤立词
5. **Cultural context**：低 affective filter（学习者觉得有趣，不焦虑）
6. **Active Recall**：Quiz + Production 强化记忆
7. **Spaced Repetition**：SRS 自动调度，1d/7d/30d 复习
8. **ZPD**：Stage 1 字幕是 scaffold，未来撤除
